# ¿Sobrevivió al Titanic?

Juego educativo interactivo para celular, pensado para actividades de ciencia de datos en clase.

Incluye dos modos:

- **Adivina un pasajero**: se muestra un pasajero real del Titanic (1912) y el alumno elige qué pistas revelar (clase, tarifa, título, familia a bordo, camarote, puerto de embarque) antes de adivinar si sobrevivió.
- **Arma tu pasajero**: el alumno construye un pasajero hipotético eligiendo todas sus características (incluida edad y sexo) y el juego responde si ese perfil habría sobrevivido, según un modelo de regresión logística entrenado con los 891 pasajeros reales del dataset del Titanic.

## Cómo jugarlo

Abre `index.html` en cualquier navegador de celular o computador. No requiere instalación ni conexión a internet una vez cargado.

Si este repositorio tiene GitHub Pages activado, también se puede jugar directamente desde el link publicado (Settings → Pages en este repositorio).
